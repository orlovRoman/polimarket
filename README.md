# Polymarket Agent Team

Команда AI-агентов для мониторинга Polymarket и других рынков предсказаний, поиска недооценённых событий, межагентного обсуждения идей и общения через Telegram.

## Что это делает
- Мониторит Polymarket как основной источник (включая CLOB стаканы заявок).
- Поддерживает подключение Kalshi, Metaculus, Manifold и других платформ через адаптеры.
- Ищет недооценённые события: купить дёшево, продать дороже до исполнения (стратегия Double-Blind).
- Даёт агентам возможность обсуждать торговые идеи между собой по двухстадийному конвейеру.
- Анализирует межрыночные корреляции в реальном времени.
- Накапливает историю цен активов для трендового анализа.
- Общается с пользователем через Telegram Bot.

## Архитектурный конвейер
1. **NEXUS Screener** (раз в 30 мин) сканирует ~1000 компактных рынков Polymarket, отбирает Top-30 кандидатов и находит корреляции.
2. **SCOUT** рассчитывает математическое преимущество (Edge) для отобранных кандидатов.
3. **SHADOW** анализирует глубину стакана (CLOB API), асимметрию Bid/Ask и 24-часовой тренд котировок.
4. **HERALD** проводит фактчекинг новостей, определяя текущий статус события.
5. Идея принимается консенсусом экспертов и отправляется пользователю.

## Основные агенты
- **NEXUS** — оркестратор, точка входа из Telegram, скринер рынков и поисковик корреляций.
- **SCOUT** — ищет математически недооценённые рынки и кросс-платформенный арбитраж.
- **SHADOW** — анализирует ликвидность, спреды, объемы и асимметрию стакана.
- **HERALD** — новостной агент, осуществляющий веб-поиск и верификацию сигналов.

## Быстрый старт
1. Создать `.env` с ключами API (`GOOGLE_API_KEY`, `TELEGRAM_BOT_TOKEN`).
2. Запустить планировщик и бота: `python main.py`.
3. Использовать команду `/scan` в Telegram для выбора категории и запуска обсуждения.
