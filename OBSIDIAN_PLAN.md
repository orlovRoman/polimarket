# План интеграции Obsidian-памяти (Obsidian Memory Integration Plan)

Этот документ описывает пошаговый план реализации полноценной работы с памятью через Obsidian, как описано в `MEMORY_POLICY.md` и `agents/orchestrator/GEMINI.md`.

## Шаг 1: Создание Obsidian Adapter (Python API для Markdown)
**Статус:** Готово ✅
**Задача:** Создать модуль `agents/shared/utils/obsidian_adapter.py`.
**Описание:** Этот класс обеспечит безопасное создание, чтение и обновление `.md` файлов в структуре `vault/`.
*   Функции для работы с директориями `inbox/`, `daily/`, `projects/`, `memory/`.
*   Генерация правильных имен файлов (например, `YYYY-MM-DD-polimarket-orchestrator.md`).
*   Проверка существования директорий.

## Шаг 2: Создание базового Оркестратора с Tools
**Статус:** Готово ✅
**Задача:** Написать код `agents/orchestrator/src/agent.py`.
**Описание:** Текущая папка пуста. Нужно создать базовый класс `NexusAgent`, который использует Gemini API (через Google GenAI SDK) и предоставить ему инструменты (Function Calling) для:
*   Обращения к базе данных (через `DatabaseManager`).
*   Создания заметок в Obsidian (через `ObsidianAdapter`).

## Шаг 3: Автоматическая генерация Daily Summary
**Статус:** Готово ✅
**Задача:** Создать скрипт `agents/orchestrator/scripts/generate_daily.py`.
**Описание:** Скрипт будет извлекать из SQLite (`discussions`, `signals`) события за прошедший день, передавать их Оркестратору (NEXUS) с задачей сформировать отчет в формате, указанном в `GEMINI.md`, и сохранять результат через `ObsidianAdapter` в `vault/daily/`.

## Шаг 4: Архивация успешных сделок (Сборка мусора / Memory GC)
**Статус:** Готово ✅
**Задача:** Создать скрипт `agents/orchestrator/scripts/memory_archiver.py`.
**Описание:** Реализация логики из `MEMORY_POLICY.md`. 
*   Скрипт проверяет сигналы, перешедшие в статус подтвержденных/успешных.
*   Извлекает историю обсуждения.
*   Генерирует "постмортем" заметку (почему идея сработала) и кладет ее в `vault/memory/durable/`.
*   Удаляет старые (сырые) обсуждения из базы SQLite для экономии токенов и места.
