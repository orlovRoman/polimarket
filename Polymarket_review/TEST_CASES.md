# TEST_CASES.md — Критичные сценарии

## SCOUT
- Рынок с явной недооценкой → должен сгенерировать сигнал с edge > 0.1
- Два похожих рынка на разных платформах с расхождением > 0.15 → сигнал арбитража

## SHADOW
- Кошелёк из watchlist делает крупную ставку → сигнал инсайдера

## NEXUS + Telegram
- `/ideas` без активных идей → корректный ответ "нет идей"
- `/discuss [url]` → запуск обсуждения и минимум два мнения (SCOUT+SHADOW)
