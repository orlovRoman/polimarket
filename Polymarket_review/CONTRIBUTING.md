# CONTRIBUTING.md

## Правила вклада
- Держи изменения маленькими и атомарными.
- Сначала обновляй `DECISIONS.md`, если меняешь архитектурное решение.
- Если меняешь контракт данных, обновляй `INTERFACES.md` и `SCHEMAS/`.
- Если добавляешь новую платформу, обновляй `ADAPTERS.md`.
- Если меняешь порядок работ, обновляй `TASKS.md`.

## Стиль
- Предпочитай короткие функции и явные интерфейсы.
- Не тащи большой контекст в код.
- Используй README и карту чтения вместо длинных объяснений.
