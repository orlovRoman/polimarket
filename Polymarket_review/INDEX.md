# INDEX.md

Центральный указатель по документам проекта.

## Быстрый доступ
- `README.md` — обзор проекта.
- `setup.md` — быстрый старт.
- `CONTRIBUTING.md` — правила вклада.
- `READING_MAP.md` — что читать для какой задачи.

## Проектные документы
- `REQUIREMENTS.md` — полные требования.
- `ARCHITECTURE.md` — схема системы.
- `AGENTS.md` — роли агентов.
- `INTERFACES.md` — контракты данных.
- `ADAPTERS.md` — подключение рынков.
- `DECISIONS.md` — принятые решения.
- `CHANGELOG.md` — история изменений.
- `TASKS.md` — план работ.
- `TEST_CASES.md` — тестовые сценарии.
- `EXAMPLES.md` — примеры.
- `MEMORY_POLICY.md` — политика памяти.
- `SCHEMAS/` — JSON Schema.

## Правило использования
Если нужно быстро понять, куда смотреть, открывай сначала `READING_MAP.md`. Если нужно понять проект целиком — `README.md` и `REQUIREMENTS.md`.
