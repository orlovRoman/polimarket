# Polymarket Agent Team

Команда AI-агентов для мониторинга Polymarket и других рынков предсказаний, поиска недооценённых событий, межагентного обсуждения идей и общения через Telegram.

## Что это делает
- Мониторит Polymarket как основной источник.
- Поддерживает подключение Kalshi, Metaculus, Manifold и других платформ через адаптеры.
- Ищет недооценённые события: купить дёшево, продать дороже до исполнения.
- Даёт агентам возможность обсуждать торговые идеи между собой.
- Позволяет подключать несколько критиков, не только Claude.
- Общается с пользователем через Telegram.

## Основные агенты
- **NEXUS** — оркестратор и точка входа из Telegram.
- **SCOUT** — ищет недооценённые рынки и кросс-платформенный арбитраж.
- **SHADOW** — мониторит инсайдерские кошельки и подтверждает идеи.
- **HERALD** — новостной агент, делается в последнюю очередь.

## Быстрый старт
1. Создать `.env` с ключами API.
2. Настроить Telegram Bot Token.
3. Реализовать `platforms/base_adapter.py` и `platforms/polymarket.py`.
4. Подключить SCOUT и NEXUS.
5. Добавить SHADOW и пул критиков.
6. Затем подключить HERALD.

## Приоритет разработки
1. Ядро и Telegram-интерфейс.
2. SCOUT и NEXUS.
3. SHADOW и межагентное обсуждение.
4. Подключение других рынков.
5. HERALD как последний этап.
6. Автотрейдинг — только после стабильного MVP.

## Принципы
- Меньше контекста в чате, больше формальных файлов.
- Один интерфейс для всех рынков.
- Несколько моделей-критиков вместо одной.
- Источники новостей без Twitter/X.
