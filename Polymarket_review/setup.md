# setup.md

## Быстрый старт
1. Создай `.env`.
2. Добавь ключи Telegram, Gemini, Anthropic и Polymarket.
3. Установи зависимости.
4. Запусти `main.py`.

## Что настроить сначала
- Telegram Bot Token.
- Gemini API Key.
- Polymarket API доступ.
- Reddit API для новостей.
