# CHANGELOG.md — История изменений

## 2026-07-25 — v2.3
- **Удаление стратегии Compound Chains (Parlays)**: Экспресс-цепочки полностью удалены из архитектуры, структуры SQLite базы данных (`db.py`), трекера исходов (`outcome_tracker.py`), веб-интерфейса и шаблонов. Добавлен скрипт миграции `scripts/drop_compound_chains.sql`.
- **Сеть и Graceful Shutdown**: Восстановлен сокет-флаг `SO_REUSEPORT`, реализовано корректное завершение процесса Uvicorn (`main.py`), исправлены проверки Telegram bot token в `telegram/bot.py`.
- **Оптимизация инфраструктуры сервера (`agent-gemini-cli-poly`)**: Создан и активирован 2 ГБ swap-файл (`/swapfile`) на хосте Debian с постоянным монтированием в `/etc/fstab` для предотвращения OOM при интенсивном сканировании.

## 2026-05-21 — v2.1
- **Интеграция Polymarket CLOB API**: Получение стакана заявок (спред, топ-бид/аск, глубина 5 уровней, асимметрия объемов) для SHADOW.
- **Инфраструктура истории цен**: Добавлена новая таблица `price_history` в БД SQLite, автоматическая запись цен на каждом цикле и очистка данных старше 7 дней.
- **Межрыночные корреляции (NEXUS SCREENER)**: NEXUS теперь раз в 30 мин сканирует компактные списки из ~1000 рынков, отбирает Top-30 кандидатов и автоматически находит корреляции (causal, inverse, arbitrage, thematic), анонсируя их в Telegram.
- **Оптимизация расходов на модели**: Все агенты (SCOUT, SHADOW) переведены по умолчанию на `gemini-2.5-flash` для экономии токенов. Для NEXUS добавлен выбор `gemini-3.5-flash` и `gemini-2.5-pro` в Telegram.

## 2026-05-28 — v2.2
- **Удаление HERALD**: Агент HERALD полностью удален из архитектуры (ADR-001).
- **Интеграция источника событий**: Метаданные источника (trigger_type, source_url) перенесены в MarketContext для более точного Event-Driven анализа.

## 2026-05-19 — v2.0
- Добавлен пул критиков вместо одного Claude
- Добавлены мультиплатформенные адаптеры (Kalshi, Metaculus, Manifold)
- HERALD перенесён в фазу 3
- Добавлен список вспомогательных файлов для token-efficient разработки
