# CHANGELOG.md — История изменений

## 2026-05-21 — v2.1
- **Интеграция Polymarket CLOB API**: Получение стакана заявок (спред, топ-бид/аск, глубина 5 уровней, асимметрия объемов) для SHADOW.
- **Инфраструктура истории цен**: Добавлена новая таблица `price_history` в БД SQLite, автоматическая запись цен на каждом цикле и очистка данных старше 7 дней.
- **Межрыночные корреляции (NEXUS SCREENER)**: NEXUS теперь раз в 30 мин сканирует компактные списки из ~1000 рынков, отбирает Top-30 кандидатов и автоматически находит корреляции (causal, inverse, arbitrage, thematic), анонсируя их в Telegram.
- **Оптимизация расходов на модели**: Все агенты (SCOUT, SHADOW, HERALD) переведены по умолчанию на `gemini-2.5-flash` для экономии токенов. Для NEXUS добавлен выбор `gemini-3.5-flash` и `gemini-2.5-pro` в Telegram.
- **Полная реализация HERALD**: Создан системный промпт для HERALD, подключен автоматический веб-поиск и верификация сигналов, завершена логика межагентного консенсуса.

## 2026-05-19 — v2.0
- Добавлен пул критиков вместо одного Claude
- Добавлены мультиплатформенные адаптеры (Kalshi, Metaculus, Manifold)
