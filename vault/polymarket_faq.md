# Polymarket FAQ and Rules

Этот документ содержит основную базу знаний и правила для работы агентов с платформой Polymarket.
Документ автоматически индексируется системой RAG. Вы можете дополнять и изменять его.

## 1. Базовые принципы
- Polymarket — это децентрализованная платформа для рынков предсказаний.
- Исходы всегда должны разрешаться на основе проверяемых источников, указанных в правилах рынка.

## 2. Формат данных
- Все вероятности указываются в процентах от 0 до 100.
- `target` и `predicted_prob` являются основными метриками уверенности агента.

## 3. Обработка неопределенностей
- Если информации недостаточно, агент должен сигнализировать об этом, а не делать случайный выбор.
- Для рынков, где результат зависит от субъективной оценки, требуется консенсус нескольких агентов (team discussion).

## 4. Память и контекст
- Общие факты сохраняются с категорией `fact`.
- Конфигурации и предпочтения пользователя имеют приоритет над обычными фактами.
